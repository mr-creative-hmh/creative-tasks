## 🚀 الميزات والقدرات الأساسية

### 1. 🛰️ نظام التتبع الجغرافي الصامت في الخلفية (Invisible Background GPS):
- يعمل بمجرد تسجيل الدخول دون أي نوافذ منبثقة أو مقاطعة للمستخدم.
- يعتمد خوارزمية ذكية (**Haversine Throttling**) ترسل نبضة إحداثيات جديدة فقط عند التحرك لأكثر من **20 متراً** أو كل **دقيقتين ونصف** أثناء التواجد المكتبي.
- **طابور المزامنة عند انقطاع الشبكة (Offline Queue)**: حفظ الإحداثيات محلياً ومزامنتها فور عودة الاتصال.
- **مؤشر حالة حي (`GpsLiveIndicator`)** بنبض أخضر ناعم يوضح دقة الإحداثيات وتوقيت آخر اتصال.

### 2. 🗺️ خريطة الحضور الميداني والتثبيت اليدوي (`AttendanceMap.vue`):
- خريطة تفاعلية مدعومة بنظام **Leaflet** مع نطاق جغرافي مرسوم للحرم الجامعي.
- ظهور الكوادر كنقاط حية على الخريطة مع أوقات الحضور وتفاصيل القسم.
- **درج التثبيت اليدوي الحصري للمدير العام**: إمكانية النقر على الخريطة لتحديد أي موقع جغرافي وحفظه لموظف مستهدف فوراً.

### 3. 📊 تقارير الأداء وتصدير البيانات المعتمدة:
- **تصدير Excel (.xlsx) أصيل**: توليد ملفات جداول بيانات رسمية مدعومة بمحرك `PhpSpreadsheet` وتنسيقات ملونة وجداول منسقة.
- **تصدير تقرير أداء PDF وطباعة رسمية**: تنسيق مخصص للطباعة باللغة العربية مع ترويسة جامعة المأمون وتوقيع الإدارة.
- خيارات تصفية متعددة: فترات سريعة (اليوم، هذا الأسبوع، هذا الشهر، كافة الفترات)، والتصفية حسب الكلية، الموظف، نوع التكليف، وحالة الإنجاز.
- حساب ديناميكي لتوزيع الحالات (مكتملة، قيد التنفيذ، معلقة) ومقارنة أداء الأقسام.

### 4. 👥 إدارة الكوادر واستيراد الإكسل وإعادة تعيين كلمة المرور:
- استيراد جماعي للموظفين عبر ملفات Excel مع فحص البيانات وحماية الحسابات من التكرار.
- تحميل نموذج إكسل جاهز ومعبأ بأسماء الأقسام المعرفة مسبقاً (`/users/template`).
- **إعادة تعيين كلمة المرور**: زر مخصص يتيح للإدارة كتابة كلمة مرور جديدة أو توليد كلمة مرور آمنة عشوائياً بنقرة زر مع إمكانية النسخ المباشر.
- حماية الحساب الحالي من الحذف الذاتي الخاطئ (`Self-Delete Protection`).

### 5. 🎨 محرك السمات والألوان المخصص (7-Color Accent Engine):
- إمكانية التبديل الفوري بين 7 ألوان سمات راقية:
  - **السماوي (Sky)** • **الزمردي (Emerald)** • **النيلي (Indigo)** • **التركوازي (Teal)** • **الياقوتي (Rose)** • **العنبري (Amber)** • **الأرجواني (Purple)**
- شريط علوي موحد لسطح المكتب يجمع أدوات النظام (GPS، الألوان، الوضع الليلي، اللغة).
- قائمة هاتف ذكية تبسط الواجهة وتنقل الإعدادات داخل درج القائمة الجانبية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الخلفية (Backend)**: Laravel 11.x, PHP 8.3+, MySQL / SQLite, PhpSpreadsheet.
- **الواجهة الأمامية (Frontend)**: Vue 3 (Composition API `<script setup>`), Inertia.js v2, Tailwind CSS v4, Lucide Vue Icons, Leaflet Maps.
- **التصميم وتجربة المستخدم**: واجهات متجاوبة بالكامل (Desktop / Tablet / Mobile First)، دعم كامل للـ RTL/LTR، والوضع الليلي (Dark Mode).

## ⚙️ متطلبات التشغيل والتثبيت

```bash
# 1. استنساخ المشروع
git clone https://github.com/mr-creative-hmh/almamon-tasks.git
cd almamon-tasks

# 2. تثبيت مكتبات PHP و JavaScript
composer install
npm install

# 3. إعداد ملف البيئة والمفتاح
cp .env.example .env
php artisan key:generate

# 4. ترحيل قاعدة البيانات وزرع البيانات الأولية
php artisan migrate --seed

# 5. بناء الواجهات وتشغيل خادم التطوير
npm run build
php artisan serve
```
